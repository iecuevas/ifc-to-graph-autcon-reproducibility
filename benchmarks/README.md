# Benchmark models

The study uses the same eight benchmark model names reported in Zhu, Wu, and Lei (2023): Institute, Smiley, House, Bridge 1, Bridge 2, Hospital Parking, KIT Bridge, and Revit Sample.

`model_manifest.csv` records file-size/entity/class metadata and source categories exactly as reported in Table 2 of that publication. The current package does **not** contain IFC binaries because redistribution rights have not yet been verified.

No cryptographic file hashes are provided because the evaluated IFC files were not present in the supplied repository ZIP. If the exact benchmark binaries are recovered, compute SHA-256 values before public release and add them to the manifest; do not substitute similarly named files without verification.

Reference: J. Zhu, P. Wu, and X. Lei, “IFC-graph for facilitating building information access and query,” *Automation in Construction*, vol. 148, 104778, 2023. DOI: 10.1016/j.autcon.2023.104778.
