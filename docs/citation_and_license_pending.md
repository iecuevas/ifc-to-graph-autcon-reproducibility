# Citation and license: author action required

The supplied institutional source snapshot contains no `LICENSE` file. A license must therefore be approved by the relevant rights holders; it must not be inferred from dependency licenses or chosen unilaterally during packaging.

The larger project's original `pyproject.toml` also contains author metadata that may not represent the complete authorship/contributor set of the four files released for the paper. For that reason, this package includes `CITATION.cff.template` rather than a final `CITATION.cff`.

Before public release:

1. confirm who should be credited as software authors/contributors;
2. confirm who owns or is authorized to license the source files;
3. select and approve the software license;
4. replace the citation template with a final CFF file;
5. add the approved `LICENSE` file.
